# Security

This package swaps two attention functions of a separately installed package at run time and opens no network
connection of its own. Model weights and karpo-decision itself come from their own publishers; check what you
download from them.

## Reporting a vulnerability

Please report it privately through this repository's Security tab ("Report a vulnerability"), not in a public
issue. If that option is not shown, open an issue saying only that you have a security report, and a maintainer
will arrange a private channel.

## Supported versions

The latest release.
